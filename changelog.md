# Changelog

Значимые изменения Sabacc. Правила ведения: [docs/agents/rules/changelog.md](docs/agents/rules/changelog.md).
История начинается с добавления этого журнала; прошлые релизы не реконструированы.

## [Unreleased]

### Added

- После «Закрыть» на результате раунда, пока соперник не закроет своё окно,
  показывается «Ждем действий соперника».
- На ход, на результат раунда и на окно победы или поражения даётся 2 минуты.
  Кольцо такое же, как при выборе жетонов. Если ход не сделан, он переходит сопернику.
  Если результат раунда не закрыт, игрок проигрывает, а соперник побеждает.
  Если после победы или поражения не выйти в меню, игрока возвращает туда и комната закрывается.
- Если игрок вышел или отключился, две минуты можно вернуться: кнопка «Играть»
  становится «Вернуться», ход замирает, соперник видит «Соперник вышел, ожидаем возвращения».
  Без возврата вышедшему засчитывается поражение. Если ушли оба, партия удаляется
  по более раннему таймеру.
- В конце партии может быть исход «НИЧЬЯ»: при полностью равных руках, если фишек
  не осталось у обоих, и если после раунда никто не нажал «Закрыть».
- Игрок, который уже выбрал жетоны, видит надпись «Соперник выбирает жетоны»,
  пока соперник не подтвердит свой набор.
- У соперника на поле видны три одинаковые фишки без названия.
  Число фишек равно жетонам, которые у него ещё не сыграны.
- При наведении на жетон в партии показываются его название и описание.
- На выбор жетонов даётся 2 минуты, в окне виден обратный отсчёт.
  Если набор не подтверждён, игроку назначаются «Бесплатный розыгрыш», «Возврат» и «Хищение».
- Добавлена инструкция запуска на Linux-сервере (`docs/how-to/server-deploy.md`):
  тот же Compose, замена исторического IP и ограничения без HTTPS
  ([SCRUM-28](https://isa-sabacc.atlassian.net/browse/SCRUM-28)).
- Добавлен базовый GitHub Actions CI: frontend lint, проверка формата заголовка PR
  и актуальности ветки относительно `main`
  ([SCRUM-25](https://isa-sabacc.atlassian.net/browse/SCRUM-25)).
- Добавлен `scripts/dev.sh`: сборка и запуск локального стенда одной командой,
  отдельные команды управления контейнерами и просмотра логов.

- Добавлены инструкции и контекст для агентов, правила веток и работы с Jira/GitHub,
  шаблон pull request и порядок ведения changelog.
- Добавлены инструкции для команды: локальный запуск, диагностика, путь от Jira до PR,
  критерии готовности и базовая архитектура; уточнены ограничения конфигурации в README.
- Добавлен Cursor skill `jira-context`: по ссылке или ключу Jira-задачи агент собирает
  описание, критерии приёмки, комментарии и связи и сопоставляет их с кодом проекта
  ([SCRUM-26](https://isa-sabacc.atlassian.net/browse/SCRUM-26)).

### Changed

- На игровой стол вернули прежние изображения карт и рубашек колод.
- Номер новой комнаты — наименьший свободный, начиная с 1.
  Если 1, 2 и 3 заняты, создаётся комната 4.
- В `Project.md` правила Kessel Sabacc приведены к мини-игре Star Wars Outlaws:
  личный банк раунда и налог проигравшего, три хода в раунде вместо лимита в три раунда,
  иерархия рук и 16 жетонов смены
  ([SCRUM-27](https://isa-sabacc.atlassian.net/browse/SCRUM-27)).
- Уточнены инструкции агентов: уровни чтения в `AGENTS.md`, lint как known-red вне
  lint-задач, действия при `403` на push (collaborator или fork+PR), сжатие
  `project-context.md` относительно архитектуры; срез проверок вынесен в
  `docs/agents/verification-history.md`.
- Формат заголовка PR: `SCRUM-<номер> Краткое описание с заглавной буквы`
  ([SCRUM-25](https://isa-sabacc.atlassian.net/browse/SCRUM-25)).

### Fixed

- При нажатии «Сдаться» сразу открывается результат партии с поражением у сдавшегося игрока и победой у соперника.
- Когда из партии вышли оба игрока, комната удаляется из базы и больше не хранится.
- Жетон можно потратить только в свой ход. В ход соперника фишки не нажимаются
  и не исчезают из руки.
- После «Закрыть» на результате раунда игра не продолжается, пока то же самое
  не сделает соперник. У того, кто уже закрыл окно, виден экран
  «Ждем действий соперника», таймер хода в это время не идёт.
- На экране ожидания больше не просвечивает номер комнаты.
  После выхода из партии «Соперник выбирает жетоны» не остаётся на следующей игре.
- Окно выбора жетонов открывается один раз за комнату и не появляется снова,
  если игрок возвращается в уже идущую партию из меню.
- Создатель комнаты видит выбор жетонов сразу, как только сел второй игрок,
  без обновления страницы. Кольцо таймера остаётся кругом при узком окне.
- Исправлены ошибки и предупреждения frontend ESLint без отключения правил:
  уточнены типы, удалён неиспользуемый код, исправлены порядок хуков и очистка подписок.
  ([SCRUM-30](https://isa-sabacc.atlassian.net/browse/SCRUM-30)).

- Пока второй игрок не сел за стол, обрыв сокета создателя комнаты больше не завершает её
  ([SCRUM-29](https://isa-sabacc.atlassian.net/browse/SCRUM-29), Bugs.md C8).
- «Зайти» открывает выбранную комнату, а обновление страницы возвращает в свою
  ([SCRUM-29](https://isa-sabacc.atlassian.net/browse/SCRUM-29), Bugs.md H1).
- Одновременное «Играть» сажает обоих в одну комнату; неудачный вход не оставляет игрока без сессии
  ([SCRUM-29](https://isa-sabacc.atlassian.net/browse/SCRUM-29), Bugs.md H14).
- Модалка кубиков больше не скрывается при выпадении `1`; карта номинала `1`
  снова показывает лицо, а не рубашку
  ([SCRUM-24](https://isa-sabacc.atlassian.net/browse/SCRUM-24), Bugs.md C4, H10).
- Исправлен запуск Gradle wrapper на Unix; Docker-сборка backend использует
  закреплённую проектом версию Gradle и собирает исполняемый `bootJar`.
- Добавлены `.dockerignore` для frontend/backend: локальные зависимости,
  результаты сборки и файлы окружения исключены из Docker-контекста.
- Инструкция запуска дополнена проверенным сценарием Compose и выбором JDK 21;
  фактический срез проверок зафиксирован в `docs/agents/verification-history.md`.
